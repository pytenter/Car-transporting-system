# 新能源物流调度策略对比报告

本报告基于 `results/summary_cplex.json` 中的实验结果生成，用于展示在线动态调度策略与 CPLEX 静态全信息优化基线之间的对比。实验开启多车协同模式，覆盖 `small / medium / large` 三种规模。

## 1. 评价指标

| 指标 | 含义 | 趋势 |
|---|---|---|
| `completed` | 完成任务数 | 越高越好 |
| `unserved` | 未完成任务数 | 越低越好 |
| `overtime` | 超时任务数 | 越低越好 |
| `distance` | 总行驶距离 | 越低越好 |
| `avg_response_time` | 平均响应时间 | 越低越好 |
| `charging_wait` | 充电等待时间 | 越低越好 |
| `score` | 综合收益得分 | 越高越好 |

综合得分同时考虑响应时间、路径距离、充电等待、超时惩罚和未完成任务惩罚，因此是本实验的主要排序指标。

---

## 2. Small 场景

### 2.2 分析

在小规模场景中，所有策略都完成了全部任务。CPLEX 静态全信息基线得分最高，主要原因是它提前掌握全部任务信息，可以整体安排服务顺序，使平均响应时间更低，并避免超时。动态策略中，`metaheuristic_sa` 得分最高，说明在候选派单组合中进行局部搜索可以提升小规模场景下的决策质量。

## 5. 总体结论

1. 三种规模下，所有动态策略均完成全部任务，说明仿真系统在车辆、电量、载重、充电资源约束下具有稳定可行性。
2. CPLEX 静态全信息基线在 `small / medium / large` 三种规模下均取得最高综合得分，体现了全局优化基准的对照价值。
3. 动态策略虽然无法提前知道未来任务，但仍能在高负载场景下保持较高完成率，说明在线启发式策略具有实际应用意义。
4. 不同规模下最优动态策略不同：
   - `small`：`metaheuristic_sa` 表现最好。
   - `medium`：`nearest_task_first` 表现最好。
   - `large`：`reinforcement_q` 表现最好。
5. 随着规模扩大，单一规则策略的表现不一定稳定，组合式、学习式或搜索式策略更适合作为进一步优化方向。

展示时可以按以下顺序说明：

1. 先展示 `small / medium / large` 三种规模，说明项目满足多规模仿真要求。

3. 接着展示 CPLEX 静态全信息基线，说明项目完成进阶数学规划对比。
4. 最后打开 Dashboard 回放一次仿真过程，让评分老师直观看到车辆移动、任务完成、充电约束和策略结果。
